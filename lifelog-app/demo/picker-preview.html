改动点：
1. 相册下拉默认只显示常用四个：全部照片 / 相机 / 视频 / 截图（照你说的，默认就是相机和视频）；
2. 其余真实相册收进「更多相册」，点开才展开；
3. 缓存相册（MicroMsg / WeiXin / cache 等）即使展开也沉底并置灰，顶部提示隐藏数量，可"显示"；
4. 网格里的实况徽标修复：选图器里用文件路径检测实况（之前用 content:// 读不到头，徽标从不显示）。

选图器网格三连问题：大图不显示 / 图片串位重复 / 滑动掉帧

根因是同一个：网格现在用 expo-image 直接解码 content:// 全尺寸原图（1200 万像素的照片整张解码到 100px 格子里），大图直接解码失败 → "大一点的图片不出现"；解码慢导致格子被复用时上一张的图还挂着 → 下滑时"上方出现下面的图"的串位；整页解码压力大 → 掉帧闪烁。

修复方案：
1. 网格缩略图改用 RN 原生 Image（Fresco 解码器）——它对 content:// 会按视图尺寸降采样解码，大图小图都稳，原生缓存也更快；
2. 关掉交叉淡入过渡（串位的直接来源）+ 固定格子尺寸加 getItemLayout（消除滑动跳动）；
3. 分页参数调优（降低每批渲染数量），点开放大预览仍用原图。

直接修无需确认的修复清单

  • 同步时回填封面："同步相册影像"完成后，对没有封面的影视/地点记录直接按标题重新搜索并下载封面（现在只在启动时做一次且容易漏，改为同步后立即补齐）。
  • 豆瓣搜索加固：加 8 秒超时（昨晚的"不返回"就是请求挂死），失败/超时安静降级，不阻塞界面。
  • 实况播放完回封面帧：详情页实况视频播完自动回到静帧封面（现在是停在最后一帧/黑屏）。
  • 轨迹开关连动起终点：轨迹关掉时，旅票的出发/到达标点一并隐藏，只留地点标点。
  • 去掉"导出轨迹"按钮：地图页只留 缩放/显示全部/轨迹开关。
  • 编辑页不自动弹联想：联想只在输入框获得焦点（你点进去）后才检索，进入编辑页/改名过程不弹。
