这版按你说的改了什么

  • 随笔是一级，下面分日记和事迹：类型弹层 4 张卡，选「随笔」后下面出现 日记 / 事迹 两个二级标签（和旅票选机票/火车票一样）。
  • 列表、详情页版式没动：还是你现在的样子（列表：封面 + 标题 + 日期 + 星级 + 摘要；详情：头部卡 + 评分卡 + 「相关影像（长按可设为封面）」）。
  • 所有类型统一显示标签：机票 / 火车票 / 地点 / 电影 / 剧集 / 书籍 / 日记 / 事迹……都带一个同款标签，不再只有随笔类才有。
  • emoji 不在角标上了：封面角标整块去掉；随笔类没照片时，封面位显示该类型的 emoji 图标（📔 / 📝），和其他类型的图标位一致。
  • 各类型能力一致，包括换封面：详情里的影像九宫格，长按任意一张就能设为封面（当前封面带「封面」角标），这一套对日记 / 事迹同样可用。
  • 心情必填、固定 5 个：😄 🙂 😌 😤 🥱，另外保留一个可自填的输入框；没选之前「保存」是灰的。
  • 颜色仍是"一个一级类型一个颜色"：旅票蓝、地点红、娱乐紫、随笔绿（日记和事迹共用随笔的绿）。

字段（随笔）

  • 日记：标题（选填）、发生日期、天气（选填）、心情（必填）、内容、照片。
  • 事迹：标题（选填）、发生日期、心情（必填）、内容、照片（没有天气）。

数据

  • 按现有结构加一个一级类型：baseType: 'note'（随笔），subType: 'diary' | 'memo'（日记 / 事迹），复用 date / localImages / coverIndex / rating 的位置放 mood（emoji）、weather（仅日记）。
  • 要连带改：类型图标配置、筛选面板"记录类型"加 日记/事迹、搜索覆盖随笔正文、月示图配色表。
